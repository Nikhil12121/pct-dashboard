# PCT Dashboard

**Pipeline Control Tower** – A full-stack MERN dashboard for pharma R&D pipeline management.

**Personal Project by [Nikhil Bhosale](https://github.com/Nikhil12121)**

**[Live App →](https://pct-dashboard-xi.vercel.app/)**

---

## Tech Stack

- **Frontend:** React, Refine, Material UI, ApexCharts, TypeScript
- **Backend:** Node.js, Express, MongoDB
- **Auth:** Google OAuth + Demo login

---

## Features

- **Home** – Pipeline health overview, KPIs, timeline
- **Project** – Project details, health cards, milestones, risks
- **Timeline** – Gantt-style project timeline
- **KIPs** – Key Inflection Points by month
- **Milestones** – Slippage tracking with stacked charts
- **Cost/FTE** – Expenditure tables and charts
- **Risks** – Risk table with severity indicators
- **Terminated** – Terminated projects overview
